# Scout Charter

Investigate the question below in read-only mode. Do not edit files or run builds or
tests unless the question file explicitly asks for builds or tests.

Every claim must carry evidence as `path:line`. Say "not established" when evidence
is insufficient instead of guessing. Do not propose fixes. Follow the report format
and length specified in the question file. The length limit is a hard cap: prefer one
`path:line` per claim, at most two, and drop detail before exceeding it.
